# 📱 TELEGRAM MINI APP + БОТ С AI-КАМЕРОЙ: «FreshFlow AI»
## Интерактивный демонстрационный MVP для жюри кейс-чемпионата «КЛЮЧ – Уфа»

---

## 🎯 В чем главная сила этого решения для защиты?

На защите у большинства команд будут только статичные слайды.  
**У вас будет QR-код на слайде 6 или 12:**
1. Жюри наводит свой телефон на QR-код прямо во время вашего выступления.
2. У них мгновенно открывается **Telegram Mini App**.
3. В приложении работает реальная камера с видоискателем, анимацией сканирования нейросетью и симуляцией:
   - Распознавания партии томатов совхоза «Алексеевский» (г. Уфа).
   - Расчета остаточного срока и дефектоскопии.
   - Выдачи рекомендации **Smart Markdown (-35%)**.
   - Кнопками «Уценить на кассе» (SetRetail) и «В Банк еды Русь».

## 🚀 Пошаговая инструкция по запуску за 3 минуты

### Шаг 1. Мгновенная проверка в браузере (на компьютере или телефоне)
Чтобы увидеть интерфейс прямо сейчас:
1. Откройте файл [`telegram_miniapp/index.html`](file:///Users/cosmos/Desktop/%D0%9A%D0%BB%D1%8E%D1%87/telegram_miniapp/index.html) в любом браузере (Safari / Chrome).
2. Разрешите доступ к веб-камере (или используйте режим имитации).
3. Нажмите кнопку **«⚡ Выполнить AI-диагностику плода»**.

---

### Шаг 2. Размещение Mini App в интернете (нужен HTTPS для Telegram)

Telegram требует, чтобы WebApp открывался по защищенной ссылке `https://`.  
Выберите любой из 2 самых простых бесплатных способов:

#### Вариант А: GitHub Pages (Бесплатно, 2 минуты — РЕКОМЕНДУЕТСЯ)
1. Создайте публичный репозиторий на GitHub (например, `FreshFlow-app`).
2. Загрузите туда файл `index.html`.
3. Зайдите в **Settings ➔ Pages** репозитория, выберите ветку `main` и нажмите **Save**.
4. Через минуту у вас будет ссылка вида:  
   `https://ваш-логин.github.io/FreshFlow-app/`

#### Вариант Б: Vercel или Static.app (За 30 секунд без Git)
1. Перейдите на [static.app](https://static.app) или [vercel.com](https://vercel.com).
2. Перетащите файл `index.html` мышкой в окно браузера.
3. Сервис сразу выдаст вам готовую ссылку `https://...`.

---

### Шаг 3. Создание бота в @BotFather и привязка кнопки

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду: `/newbot`
3. Задайте имя (например, `FreshFlow Ufa Demo`) и юзернейм (например, `FreshFlow_ufa_bot`).
4. Скопируйте полученный **HTTP API Token**.
5. Настройте Mini App кнопку в меню (чтобы приложение открывалось слева от поля ввода):
   - Отправьте в @BotFather команду: `/mybots`
   - Выберите вашего бота ➔ **Bot Settings** ➔ **Menu Button** ➔ **Configure menu button**.
   - Отправьте ссылку из Шага 2 (`https://...`) и название кнопки (например, `📷 AI-Инспектор`).
6. Вставьте токен и ссылку в файл [`bot.py`](file:///Users/cosmos/Desktop/%D0%9A%D0%BB%D1%8E%D1%87/telegram_miniapp/bot.py):
   ```python
   BOT_TOKEN = "ваш_токен"
   WEBAPP_URL = "https://ваш_url..."
   ```
7. Запустите бота на компьютере:
   ```bash
   python3 bot.py
   ```

---

### Шаг 4. Как презентовать это жюри на защите

1. Сгенерируйте QR-код на прямую ссылку на вашего бота (например, `https://t.me/FreshFlow_ufa_bot`):
   - Можно воспользоваться любым бесплатным генератором (например, qr-code-generator.com).
2. Поместите этот QR-код на **Слайд 6 (Прототип)** и **Слайд 12 (Финал)** презентации.
3. Во время доклада на слайде 6 спикер говорит:
   > *«Уважаемые члены жюри! Вы можете прямо сейчас навести свои смартфоны на QR-код на слайде. У вас откроется наш рабочий прототип Telegram Mini App для товароведа магазина сети „Байрам“ с подключенной AI-камерой и модулем динамического дисконтирования Smart Markdown».*
