## 🌐 О проекте

**FreshFlow AI** — B2B AI-платформа для торговых сетей и распределительных центров, автоматизирующая входной контроль овощей и фруктов (ФРОВ) и исключающая списания скоропорта.

### Ключевые возможности:
* **Приёмка фуры за 8 минут вместо 50:** Оптическая оценка партии по фото с определением калибра, спелости и процента дефектов.
* **Двухэтапный ИИ-пайплайн:**
  * Ультрабыстрый инференс на **Groq LPU (1,1 с)** для экспресс-распознавания.
  * Глубокая ГОСТ-верификация через **Google Gemini 2.5 Flash (2,1 с)** по стандартам РФ (ГОСТ 34298-2017).
* **Автогенерация первичного бухгалтерского учёта РФ (.xlsx):**
  * **ТОРГ-2 (ОКУД 0330202)** — акт об установленном расхождении для удержания выплат поставщику через Диадок.
  * **ТОРГ-15 (ОКУД 0330215)** — акт оперативной уценки на 20–40% до блокировки продажи кассой.
  * **ТОРГ-16 (ОКУД 0330216)** — акт списания неликвида и вывод из системы «Честный Знак».
* **Интеграция с кассами (SetRetail, Frontol) и 1С:** Zero-CAPEX решение, работающее без закупки дорогостоящих электронных ценников.

## 🚀 Запуск сайта локально

Откройте файл `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```
Сайт будет доступен по адресу: `http://localhost:8000`
